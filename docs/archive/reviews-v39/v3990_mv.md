## V3990-1 P0：/v1/video 传 hash → 20010（已修）

- 根因实锤：`kg_direct_api_client._videoDetail` 载荷固定 `{'video_id': id}`，
  传 32 位 hash 上游必返 `error_code=20010 invalid param`。
  调用方（搜索 MV `MvHash` / 榜单 `video_hash` / 收藏 `video_hash`）手里只有 hash。
- 修复（repository 层统一收口，调用方零改动）：
  `mv_repository.fetchDetail(videoIdOrHash)` 入口判形态——纯数字直用；
  hash 形态先经 `/search`(type=mv) 用 `MvHash` 精确匹配反查 `MvID`
  （实测字段，见 search_repository._mvItem）换算 video_id，再做详情请求。
- 会话级 `_hashToVideoId` 缓存（上限 128，超过清空，第 25 条）；
  反查失败抛 `ApiException(-1, '无法将 MV hash 换算为 video_id…')`，
  不静默降级（第 9 条），MV 页由此给出「MV 不存在/已下架」空态而非黑屏。
- 与 `resolvePlayUrl` 的反向互转（video_id→hash）形成对称通道。

## V3990-2 MV 页重写（进行中）

### 旧文件 441 行缺陷自析（已全文核实）

1. 详情失败（20010）被 mvDetailProvider 吞成 null → 清晰度按钮静默消失，无重试。
2. 传 hash 进页时清晰度列表恒不可得（V3990-1 根因的 UI 面）。
3. 空数据态（/kmr 返回 `[{}]` 深链进入）无明确文案与出口。
4. 加载态只有裸转圈，无语义区分（解析中/缓冲中）。
5. 播放错误只有 `'$e'` 原始字符串，无用户可读归因。
6. 清晰度菜单有当前档 check，但**按钮主体无当前档指示**；mkv 档无容器标注。
7. 音频互斥缺失：进 MV 不暂停音频队列，两边声音叠加。
8. 生命周期：切档失败恢复 play 未判 mounted 后 setState；视频 `isPlaying` 用 `setState` 手动刷新（依赖点击触发）；后台切换（AppLifecycle）不暂停视频；横竖屏 SystemChrome 恢复 OK。
9. 收藏 `catch (_)` 吞异常统一按「需登录」提示（违反第 6/7 条）。

### 重写分区（新 mv_player_page.dart，604→605 行级别同规模）

- `_Phase` 三态枚举：loading（区分「解析中」=loading 文案 / 「缓冲中」=mvBuffering）/ normal / failed（含归因 `_errorDetail` + 重试 + 返回）；`_mvMissing`（详情空数据 / 20010 / hash 反查失败）给 mvNotExist 文案，**无重试**（资源不存在重试无意义，第 11 条触发/退出条件明确）+ 返回动作。
- 加载态：解析期转圈 + loading 文案；normal 态画面上叠加 isBuffering 转圈（区别黑屏卡死）。
- 清晰度：`_QualityPicker` 按钮主体显示**当前档 label**（active 由 activeHash 反查），菜单当前档 check 图标 + **mkv 容器档标注**（MvDetail.containers，V3990-2 新字段）。
- 音频互斥：initState 首行 `ref.read(audioHandlerProvider).pause()`（audio_handler 契约：作废音频在途世代，不会自动续播）；失败 debugPrint 留痕不阻断；不做返回自动恢复。
- 生命周期对称：控制器 dispose / 方向锁恢复 portraitUp / SystemUiMode.edgeToEdge 恢复 / 控制条自动隐藏 Timer cancel / 监听器随控制器 dispose 销毁（第 20 条）；全部异步 await 后 `mounted` 校验（18 条）；`_resolving` 互斥闸门 finally 开闸（19 条）。
- 播放错误反馈：controller.value.hasError → Toast(mvPlayError) + `_errorDetail`（errorDescription），控制条刷新改由 addListener 驱动（不再靠手点 setState）。
- 收藏异常分类：ApiException（接口失败）与普通异常分开归因，不再一律按「需登录」提示（第 6/7/16 条）。
- l10n 全覆盖：新增 6 键（mvNotExist / mvDetailLoadFailed / mvMkvContainer / audioPausedForMv / mvPlayError / mvBuffering）× 11 语言；控制条自动隐藏 4s（播放中才隐）。
